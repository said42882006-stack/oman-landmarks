# معالم سلطنة عُمان — خريطة تفاعلية

خريطة تفاعلية لمحافظات سلطنة عُمان الإحدى عشرة وولاياتها الثلاث والستين. اضغط على أي محافظة لتظهر نبذتها التاريخية وولاياتها وصور أشهر معالمها.

- الصور من ويكيميديا كومنز بتراخيص حرة، واسم المصوّر والترخيص يظهران مع كل صورة.
